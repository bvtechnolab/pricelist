Sales Multi Pricelist per Order Line

Apply different pricelists on each sale order line with an advanced comparison wizard

🚀 Overview

Sales Multi Pricelist per Order Line is a powerful Odoo module that allows sales users to apply different pricelists on each individual sale order line — instead of a single pricelist for the entire order.

When adding products to a quotation, simply click the "Apply" button next to any order line to open an advanced pricelist comparison wizard. The wizard displays all available pricelists in a clear table format, showing the calculated Unit Price, Unit Cost, Margin, and Margin % for each pricelist — so your sales team can make informed pricing decisions instantly.

⭐ Key Features

✅ Per-Line Pricelist

Assign a different pricelist to each sale order line independently.

📊 Pricelist Comparison Wizard

View all pricelists side-by-side in a table with Unit Price, Cost, Margin and Margin %.

💰 Margin Visibility

Instantly see cost price, margin amount and margin percentage for each pricelist option.

⚙ Configuration Based

Enable or disable the feature from Sales → Configuration → Settings with a single toggle.

💲 Multi-Currency Support

Prices are computed with proper currency and UoM from the order context.

💪 Taxes Auto-Recompute

Taxes are automatically recalculated after applying a new pricelist to a line.

📝 How to Use

Step 1 — Enable the Feature

Go to Sales → Configuration → Settings → Pricing section and turn ON the "Multi Pricelist per Line" checkbox, then click Save.

Step 2 — Click "Apply" on Order Line

Open any Sale Order / Quotation. You will now see a "Line Pricelist" column and an "Apply" button on each order line. Click the "Apply" button on any line to open the pricelist wizard.

Step 3 — Compare & Apply Pricelist

The wizard opens showing all available pricelists in a table with columns: Pricelist, Unit Price, Unit Cost, Margin, Margin (%). Click the "Apply" button on the desired pricelist row to apply it to the order line. The price, pricelist, and taxes will be updated automatically.
